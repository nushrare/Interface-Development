# Interface Development Coursework

Individual coursework by Anushka Jain, exported from George Brown’s Good Code Club editor. Design and creative direction by Anushka Jain, with instructor/class tutorial guidance and ChatGPT coding assistance.

## Projects

- [anuraga](anuraga/): Mobile-style wellbeing interface prototype using Bootstrap and JavaScript. Mood selection and check-in form save a demonstration entry in browser localStorage. Insights and toolkit screens are interface concepts; this is not a clinical or production health application.
- [e3](e3/): jQuery navigation exercise loading local HTML fragments into a shared page.
- [e4](e4/): Local JSON data loaded with jQuery, rendered into an HTML table, and enhanced with DataTables.
- [e5](e5/): Coursework chatbot demonstrating a JSON POST request to the Gemini API and displaying the returned text. The original embedded credential has been removed. No live API request was made during export review. Browser-side API credentials are unsuitable for production; use a server-side service for a deployed implementation.
- [e1](e1/): Introductory HTML/CSS profile page with a local image.
- [e2](e2/): Bootstrap layout exercise with an embedded video.
- [e6](e6/): Bootstrap card interface exercise.
- [a3](a3/): Interface assignment preserved as exported; JavaScript file contains a starter placeholder.

## Export notes

Nine archives contained eight distinct projects. `a4---project-prototype` and `anuraga` were byte-identical, so one copy is included. Original downloads are preserved. The Gemini credential was replaced with a placeholder. Source functionality is otherwise preserved; this export is not a claim of production readiness or successful live API testing.

Run `python3 -m http.server 8000` from this folder and visit http://localhost:8000.
