# e5

Coursework chatbot demonstrating a JSON POST request to the Gemini API and displaying the returned text. The original embedded credential has been removed. No live API request was made during export review. Browser-side API credentials are unsuitable for production; use a server-side service for a deployed implementation.

Individual Interface Development coursework by Anushka Jain, with instructor/class tutorial guidance and AI coding assistance. Design and creative direction by Anushka Jain.
