# anuraga

Mobile-style wellbeing interface prototype using Bootstrap and JavaScript. Mood selection and check-in form save a demonstration entry in browser localStorage. Insights and toolkit screens are interface concepts; this is not a clinical or production health application.

Individual Interface Development coursework by Anushka Jain, with instructor/class tutorial guidance and AI coding assistance. Design and creative direction by Anushka Jain.

## Preview
Serve the repository through a local HTTP server, then open this folder’s index.html. CDN libraries and external media require internet access.
